# 🛡️ Level 8 — Error Handling

Real programs don't always run perfectly.

I'm learning how to make programs more reliable.

### Topics

* [x] `try`
* [x] `except`
* [x] `else`
* [x] `finally`
* [x] Raising exceptions
* [x] Custom exceptions
* [x] Debugging
* [x] Logging

Example:

```python
try:
    number = int(input("Enter a number: "))
    print(100 / number)

except ValueError:
    print("Please enter a valid number.")

except ZeroDivisionError:
    print("Cannot divide by zero.")
```
